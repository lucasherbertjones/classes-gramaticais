# Classes Gramaticais

Jogo interativo para aprender as classes gramaticais da língua portuguesa.

**Jogar:** https://lucasherbertjones.github.io/classes-gramaticais/

- 12 níveis: das 4 classes básicas até a classificação completa escrita por extenso
- Cores fixas por classe para ajudar a memorizar
- Começa pelo verbo, o centro da oração
- O que você já domina é pulado por mais tempo a cada acerto, e volta de vez em quando para conferir
- Histórico de respostas exportável em CSV

O jogo é um único arquivo (`index.html`) e roda inteiro no navegador. O progresso fica salvo só no navegador de cada jogador.
